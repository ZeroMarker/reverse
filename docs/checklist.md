# 检查表与速查

## 分析前

- [ ] 已确认样本所有者和授权范围
- [ ] 已写下要回答的具体问题
- [ ] 已建立隔离、可回滚的分析环境
- [ ] 已关闭不必要的共享目录、剪贴板和网络
- [ ] 已保存只读原件与工作副本
- [ ] 已记录 SHA-256、大小、来源、时间和工具版本

## 静态分析

- [ ] 确认真实文件格式、架构和运行时
- [ ] 检查签名、节区/段、资源、导入导出
- [ ] 提取字符串并检查交叉引用
- [ ] 识别编译器、打包器、混淆或托管运行时线索
- [ ] 区分反编译推测与汇编事实
- [ ] 重命名函数、变量和结构体并记录依据
- [ ] 列出下一步需要动态验证的假设

## 动态分析

- [ ] 已恢复到干净快照
- [ ] 观测点与待验证问题一一对应
- [ ] 记录参数、返回值、内存和系统副作用
- [ ] 留存必要的调试日志或流量记录
- [ ] 使用不同输入重复实验
- [ ] 将运行时地址和类型回填到静态数据库

## 报告

- [ ] 写明范围、环境、样本哈希和工具版本
- [ ] 将事实、推断、待验证项分开
- [ ] 给出可复现步骤和证据位置
- [ ] 说明局限性与可能的替代解释
- [ ] 清除报告中的密钥、个人数据和受限样本内容

## 常用安全命令

```bash
# 哈希与基本识别
sha256sum sample
file sample

# 可读字符串（不执行目标）
strings -a -n 6 sample | less

# ELF 元数据（不执行目标）
readelf -hW sample
readelf -lW sample
readelf -dW sample

# PE/ELF/Mach-O 通用扫描可选 Detect It Easy 或对应平台工具
```

未知样本的“查看版本”“运行帮助”或双击启动都属于执行行为，不是安全的文件识别方式。
